# Introducción

Existen diversos métodos que permiten calcular el valor de algunas integrales, muchos de los métodos se pueden implementar mediante código para facilitar el proceso de calcular el valor de varias integrales. Uno de esos métodos se llamma **Cuadratura Gaussiana**, este método es bastante útil y da valores exactos con excepción de error de precisión de máquina. 

El objetivo es resolver integrales del siguiente tipo:

\begin{align}
\int_a^b {\rm{d}}x f(x)
\end{align}

La integral anterior se puede resolver mediante el método de Cuadratura Gaussiana, el cual consiste en encontrar un N que de la solución exacta con excepción de precisión de máquina calculando los puntos y los pesos.
